# 🎨 Vee Cartoon Studio

**Vee Cartoon Studio** is a browser-based AI Cartoon Creator, Story-to-Animation Builder, and Video Studio designed to run on mobile phones, tablets, and desktop computers.

---

## 📱 How to Deploy Using an Android Phone

### Step 1: Prepare Code Files
1. Download a free text editor on Android (such as **Acode** from Google Play Store).
2. Create a new file named `index.html` and paste the provided application code.
3. Save the file to your Android internal storage.

### Step 2: Upload to GitHub
1. Open your browser and go to [GitHub.com](https://github.com).
2. Tap the **+** icon in the top right -> **New repository**.
3. Name your repository `Vee-Cartoon-Studio` and select **Public**.
4. Tap **uploading an existing file** and select your `index.html`.
5. Tap **Commit changes**.

### Step 3: Turn on GitHub Pages
1. Go to **Settings** in your GitHub repository.
2. Scroll to **Pages**.
3. Set **Source** to `Deploy from a branch`.
4. Select `main` (or `master`) branch and `/ (root)` folder.
5. Tap **Save**. Your site will be live at `https://<your-username>.github.io/Vee-Cartoon-Studio/`!

## 🛠️ Features
- **Character Creator**: Interactive controls for character expression, mood, and art style.
- **Aspect Ratio Exporter**: Switch between 9:16 (Shorts/Reels), 16:9 (YouTube), and 1:1 (Instagram).
- **Text-to-Speech Engine**: Speaks captions and dialogue in real-time.
- **Privacy First**: Optional external AI keys (HuggingFace / OpenAI) are stored locally in the browser and never exposed publicly.
